# ATHRBRANDS Website V4 — Art Direction & Quality Gate

## Status
This document is the single source of truth for the website redesign. No implementation is approved for production until the static art direction is reviewed on mobile and desktop.

## Core position
ATHRBRANDS is a Saudi studio specializing in brand strategy and visual identity systems for ambitious brands.

Arabic positioning:
> استوديو سعودي متخصص في استراتيجية وتصميم الهويات البصرية للعلامات الطموحة.

Primary idea:
> هوية تُرى. أثرٌ يبقى.

## Approved visual identity
- Deep charcoal / black as the primary field.
- Quiet, restrained gold used only for hierarchy and key details.
- Warm ivory for readable text.
- Generous negative space.
- Editorial composition with disciplined geometry.
- Minimal ornamentation; every element must support meaning.
- No generic luxury clichés, random radial graphics, or unrelated decorative shapes.
- The approved ATHR seal and official ATHRBRANDS wordmark must be used without redesigning them.

## Typography gate
The supplied “أثر المسار” and “ATHAR TRACE” materials are image specimens, not production font files. No website may claim to use them until actual OTF, TTF, WOFF, or WOFF2 files are available.

Until then:
- Use the official wordmark as a vector/image asset where required.
- Use a temporary production-safe type pair only for prototype review.
- Mark the prototype typography as provisional.
- Do not publish the prototype to production as the final identity implementation.

## Homepage hierarchy
1. Minimal navigation and official wordmark.
2. One strong positioning statement with no decorative overload.
3. Selected Work using authentic case-study assets.
4. Studio point of view.
5. Process: Discover, Define, Design, Activate.
6. Three service pillars only.
7. Evidence / insights.
8. Strong start-a-project CTA.

## Selected Work requirements
Each project must look unmistakably connected to its actual identity system.

### ATHRBRANDS
Use authentic ATHRBRANDS case-study pages, logo system, charcoal/gold/ivory palette, and official seal.

### QIRĀ
Use authentic QIRĀ project assets: logo, hospitality imagery, material palette, Arabic/English lockup, and real case-study applications. Do not represent it with a generic arch placeholder.

### WIZAN
Use authentic WIZAN project assets: logo, wellness data system, green palette, app/report applications, and real case-study visuals. Do not represent it with a generic orbital placeholder.

Each card/section must include:
- Project name.
- Sector.
- Scope.
- One clear creative idea.
- Authentic visual asset.
- Link to a dedicated case-study page.

## Conversion principles
- The first screen must explain what ATHRBRANDS does within five seconds.
- Copy must be human, specific, and easy to scan.
- Primary CTA: ابدأ مشروعك / Start a project.
- Secondary CTA: استكشف الأعمال / Explore work.
- Prices are not shown before value is established.
- The project form must be concise and qualification-focused.

## Mobile-first quality gate
- No headline collision or oversized typography.
- Arabic RTL must be native and readable.
- Text contrast must pass practical mobile readability.
- Navigation must not compete with the hero.
- Project visuals must remain clear at 390 px width.
- No browser-height tricks that create awkward empty space.

## Review sequence
1. Content architecture.
2. Static mobile art direction.
3. Static desktop art direction.
4. Typography approval.
5. Authentic project assets added.
6. Interaction prototype.
7. Responsive implementation.
8. Accessibility, language, and performance QA.
9. Vercel preview approval.
10. Merge to production.

## Non-negotiable QA
- Arabic proofreading word by word.
- Official name always written: ATHRBRANDS.
- No invented client claims or results.
- Concept projects labeled clearly as conceptual.
- No placeholder visuals in the final site.
- No production merge without user approval.
